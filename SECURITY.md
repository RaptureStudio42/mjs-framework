# Politique de sécurité

## Versions couvertes

Seule la dernière version publiée sur npm (`mjs-framework`) reçoit des correctifs de
sécurité. Il n'y a pas de branche de maintenance pour les versions antérieures.

## Signaler une faille

Merci de **ne pas ouvrir d'issue publique** pour signaler une faille de sécurité. Utilisez le
formulaire privé GitHub « Report a vulnerability » du dépôt :
<https://github.com/RaptureStudio42/mjs-framework/security/advisories/new>.

Merci d'inclure, si possible :

- une description du problème et de son impact ;
- les étapes pour le reproduire ;
- la version de `mjs-framework` concernée.

Vous recevrez une première réponse sous quelques jours.

## Remerciements

Merci à toute personne qui prend le temps de signaler une faille de façon responsable — la
qualité du projet lui doit beaucoup.
